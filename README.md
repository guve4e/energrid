# Energrid

Energrid is a local-first platform for residential and commercial installations. A shared deterministic Core provides domain behavior; API adapters, site services and the Portal connect it to people, devices and deployment environments.

## Engineering handbook

Start at the [handbook index](docs/index.md) for the architecture, lifecycle, persistence, operations and integration guides. The index also links to the existing topic documents.

To preview the handbook locally:

```sh
pnpm install
pnpm docs:dev
```

The generated Nx starter instructions have been removed. For application commands and current runtime setup, use the [local operations guide](docs/operations.md).
