## Mandatory Engineering Instructions

Before starting any implementation or refactoring task:

1. Read `ENGINEERING.md` in full.
2. Read `docs/README.md`, `docs/STATUS.md`, and `docs/NEXT.md`.
3. Read relevant architecture documents and existing ADRs.
4. Inspect Git status and the existing implementation.

Follow `ENGINEERING.md` throughout development.

Apply SOLID, Clean Architecture, dependency injection,
Kent Beck's Simple Design, and pragmatic refactoring
without introducing unnecessary abstractions.

Before completing a task:

1. Review the complete diff for maintainability and duplication.
2. Run appropriate tests, typechecks, and builds.
3. Verify actual integrated behavior where applicable.
4. Update canonical documentation with verified results.
5. Report remaining limitations and blockers.

Do not claim unperformed verification.
Do not introduce unrelated features or refactoring.
